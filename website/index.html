在工作台里找岗位、按 JD 改简历、稳妥管理每一次投递。

Resume Grill 把分散在本地文件夹、招聘网站和邮箱草稿里的求职流程收进同一个本机工作台。支持管理多版本简历、读取公司招聘官网、连接本机浏览器筛选 BOSS 岗位、对照 JD 逐条核对改写、生成邮箱预览与官网申请表代填——所有简历和投递记录保存在本机 SQLite，每一次外发都由你本人确认。

WORKBENCH MODULES

六个工作台入口，覆盖从整理解历到跟进回执

默认启用完整工作台能力；也可在 DSH 设置或 Profile 配置中按需停用 boss、mail、website 模块，已存求职资料始终保留。

简历库

支持拖拽导入 PDF、DOCX、TXT、Markdown 或粘贴文字新建，查看原文件、搜索摘要、编辑另存派生副本并保留版本来源关系。删除移入回收站可撤销恢复，不会误删派生版本与已投递附件。

  • 未改正文时直接沿用原 PDF；改写后生成可选中文字的单栏岗位 PDF
  • 自动识别原 PDF 首页上方独立证件照并带入新版本；扫描件支持本机 Tesseract OCR

招聘官网

新建或打开求职目标，实时读取公司官网静态页、动态页面及公开招聘接口，记录读取时间与失败原因。点击具体职位拉取当前 JD 并匹配简历，也可直接打开官网手动申请。

  • 每次 JD 更新生成独立上下文，旧修改建议不会误套到新 JD
  • 仅访问公开 HTTPS 页面并限制请求边界，绝不捏造 JD 或招聘邮箱

BOSS 投递

含实验功能

通过内置本机执行器连接已安装的 ego、Edge 或 Chrome，按所选简历和招聘类型（实习、校招、全职）从当前页最多核对 10 份完整 JD，对照检查届别、学历、工作年限、到岗时间与城市。

  • 核对前可增减岗位、单岗切换简历、上下调整发送顺序或归档批次
  • 自动发招呼与简历图片属于实验功能，遇登录或安全验证会立即暂停交由你处理

邮箱投递

选好简历、填写收件邮箱即可生成投递预览，支持修改收件人、主题与正文，也可按求职目标批量准备邮件草稿。内置 QQ、163、126 邮箱配置，企业邮箱支持自定义 TLS / STARTTLS。

  • SMTP 授权码保存到 DSH 凭据服务，不进入聊天参数或插件数据库
  • 开启真实发送开关后，仍需核对实际附件并手动输入确认才能发出

官网代填

将简历解析并确认为可复用的教育、工作、项目、竞赛与校园经历资料。从岗位卡片打开专用 Edge 或 Chrome 窗口，自动填写能识别的标准申请表、附上所选简历并执行字段回读核对。

  • 跳转第三方 ATS 申请页时清晰提示目标域名，确认后再继续填写
  • 账号登录、验证码与最终点击提交全程留给用户在官网完成

投递记录

在同一张列表汇总查看 BOSS 投递回执、招聘官网提交记录与 SMTP 邮件状态。可随时登记「等回复、已约面、已结束」及面试备注，并用「到期跟进」筛出今天与逾期的待办事项。

  • 同一 DSH 会话切回分页自动恢复上次浏览的详情、搜索词与筛选条件
  • 支持左侧完整工作台与右侧「求职快开」侧栏协同查阅

WORKFLOW

清晰可控的四步求职闭环

把重复搜集与格式整理的体力活交给工具，把简历措辞取舍与最终投递决定留给自己。

  1. 01

    导入主简历与拆解资料

    上传 PDF / DOCX / Markdown 简历，保留原件的同时，按需拆解为可复用的教育、工作与项目经历结构。

  2. 02

    拉取官网与 BOSS 岗位

    按求职方向读取公司招聘官网实时 JD，或通过本机浏览器读取并核查 BOSS 岗位条件与筛选依据。

  3. 03

    勾选修改并冻结附件预览

    逐条勾选要采纳的简历改写建议或手动润色正文，另存岗位版 PDF，生成待核对的邮件草稿、BOSS 批次或代填表单。

  4. 04

    人工确认外发与定期跟进

    核对收件人、正文与实际附件无误后手动确认发送；所有渠道记录自动归集到「投递记录」，按跟进日期提醒复盘。

LOCAL-FIRST & HUMAN CONFIRMATION

本机隐私与人工确认机制

求职资料高度敏感，投递动作不可撤回。Resume Grill 在架构层面严格隔离了模型工具权限与人类确认通道。

资料仅保存在本机

简历文件、派生版本、SQLite 数据库与投递回执默认存储在 DSH_HOME/storages/resume-grill（CLI / MCP 模式为 .resume-agent），也可通过 RESUME_AGENT_HOME 指定本机目录，不上传第三方云端。

AI 无直接发信确认权限

审批确认绝不暴露为 MCP 或对话模型工具。模型只能执行读取、准备草稿、查询与暂停；真实发送必须经由原生卡片的人类专属通道、CLI 交互式 approve 或本机认证面板完成。

内容摘要与哈希严格绑定

邮件确认绑定不可变预览摘要；BOSS 批次为每个岗位独立冻结 JD、简历版本、PDF 哈希与图片哈希。一旦修改邮件、更换简历或调整顺序，旧确认立即作废，不会沿用历史授权。

凭据隔离与异常停机保护

原生 SMTP 授权码存入 DSH 凭据服务，BOSS 连接码仅驻留内存。投递前先持久化执行意图；遇到断连、超时或回执不明时立即停止后续队列并标为待核对，重启宿主也不会自动重发。

INSTALLATION & MCP

安装到 DSH 工作台，或作为标准 MCP 服务接入

普通用户可直接下载预构建 .tgz 插件包通过 DSH 官方安装器启用，无需在本机克隆仓库编译。

  1. 前往 GitHub Releases 下载最新的 resume-grill-agent-*.tgz。
  2. 打开 DSH 插件 → 添加插件 → 安装第三方插件，填写下载文件的绝对路径，启用「Resume Grill」。
  3. 从 DSH 左侧栏打开 Resume Grill（或使用底部「求职快开」快捷入口）。
使用 DSH CLI 安装（Web 版将 desktop 替换为 web） 
dsh plugin --profile desktop add 'C:/Downloads/resume-grill-agent-0.4.5.tgz'

升级新版时通过同一入口安装新 .tgz，完全退出 DSH（包含系统托盘菜单中的「退出」）后重新打开即可生效。

将以下提示词复制给具备本机终端执行权限的 AI 助手，即可自动下载并安装到你的 DSH 桌面版：

AI 安装提示词 
请把 Resume Grill 安装到我本机的 DSH 桌面版。
源码仓库 https://github.com/MIU-MA/resume-grill-agent

1. 用我提供的 .tgz，或从 https://github.com/MIU-MA/resume-grill-agent/releases/latest
   下载 resume-grill-agent-*.tgz 安装包。
2. 使用实际 .tgz 路径运行 dsh plugin --profile desktop add "<.tgz 绝对路径>"。
   dsh 不在 PATH 时查找桌面版自带的 CLI。若无法调用 CLI，把包的绝对路径给我，
   我会粘贴到 DSH 的「安装第三方插件」。
3. 告诉我安装结果。若 DSH 已在运行，请提醒我完全退出并重新打开，
   然后从左侧打开 Resume Grill。做到安装这一步就可以了。

DSH 原生插件之外，其他支持 MCP 的宿主也可直接接入同一套后端服务（同一 DSH Profile 请勿同时挂载原生插件与 MCP 以避免重复工具）：

MCP Server 配置示例 
{
  "mcpServers": {
    "resume-grill": {
      "command": "node",
      "args": ["C:/path/resume-grill-agent/dist/adapters/cli/main.js", "serve"],
      "env": { "RESUME_AGENT_HOME": "C:/path/private-resume-data" }
    }
  }
}
启动可选本机 React 面板（默认 127.0.0.1:4319）与 CLI 人工发信确认 
npm run panel
node dist/adapters/cli/main.js approve <applicationId> <digest>
按需停用可选模块（cordis.patch.yml，也可在 DSH 设置中勾选） 
- id: resume-grill
  config:
    disabledCapabilities: [mail, website]
从源码检查、测试与生成安装包（Node.js 24+，产物位于 artifacts/） 
npm ci
npm run check
npm test
npm run package:plugin
