# 官网代填

1. 在「招聘官网」打开具体岗位，选要使用的简历。首次用这份简历时核对联系方式和经历，确认后可在其他岗位复用。
2. 点「官网代填」。插件打开独立的 Edge 或 Chrome 窗口。若停在岗位详情或登录页，在窗口中进入申请表，再点一次代填。该窗口会保留自己的登录状态。
3. 在官网核对填好的内容和附件，补齐必填项，最后提交。卡片上的「已核对」表示字段回读通过，提交状态请以官网为准。

点击代填会向申请页填写你确认过的资料，网站可能在选择附件时立即上传。请在使用前确认公司和岗位。从专用浏览器首次登录时，密码、验证码和同意声明由你处理。

目前支持岗位来源同域、能识别标签的标准网页表单。字段无法确定、已有内容冲突、同名选项不唯一时会留给你处理。多段经历按可识别的表单分组填写；iframe、定制组件或跳到第三方招聘系统的页面可能需要手动处理。如果岗位跳到其他域名，可核对后把实际申请页链接导入为岗位来源。附件回读只能确认网页文件控件选中了哪份文件，上传结果请看官网显示。

DSH 卡片直接执行，无需额外配置 MCP 或模型。BOSS 岗位从「BOSS 投递」进入。[MCP 接口](mcp.md)仍提供表单规划及回读能力，供其他宿主集成。

开发验证运行 `npm run build` 和 `npm run verify:browser`。脚本用隔离的浏览器测试角色标签、回读、PDF 字节、填过的字段和提交次数，无需真实账号。可设 `RESUME_TEST_BROWSER=chrome` 切换测试浏览器。
